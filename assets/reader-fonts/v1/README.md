# Reader font catalog

30 optional families, converted to EPDFONT bitmap assets at 18, 22, 24, 25, 28, 30 and 36 px. These files are hosted separately and downloaded to microSD only after the user selects a family. They are not embedded in the firmware.

Sources: the official [Google Fonts repository](https://github.com/google/fonts). Each family retains its original SIL Open Font License alongside its assets. Checksums and sizes are recorded in [catalog.json](catalog.json).
